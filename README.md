# LangAI — AI Language Learning Platform

## Setup (5 minutes)

### 1. Install dependencies
```
npm install
```

### 2. Set your API key
Copy `.env.example` to `.env`:
```
cp .env.example .env
```
Edit `.env` and add your Anthropic API key:
```
ANTHROPIC_API_KEY=sk-ant-...
```
Get your key at: https://console.anthropic.com

### 3. Start the server
```
npm start
```

### 4. Open in browser
Go to: **http://localhost:3000**

---

## How to use

1. Go to `http://localhost:3000/register.html` — create your account
2. You'll be redirected to the full app dashboard
3. All 10+ AI features are ready to use
